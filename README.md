# Awesome-Low-Code-Workflow-Automation

## Top Low-Code Workflow Automation Tools Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**  

*Focused on Visual Workflow Building, Business Process Automation & Cross-Application Orchestration*  

**Last updated: March 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Low-Code Workflow Automation Tools**. These tools enable business users and developers to build automated workflows through visual builders, drag-and-drop interfaces, and declarative configuration — connecting apps, databases, and APIs without extensive coding.



**Examples** include Salesforce Flow Builder, Zapier, Make, Microsoft Power Automate, Tray.io, n8n Cloud, Workato, Kissflow, Appian, and Quickbase (the category leaders).



**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom workflow logic, and transparent automation — ideal for teams prioritizing data control, avoiding per-task pricing, and building data-sovereign automation infrastructure.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms



- **[Salesforce Flow Builder](https://www.salesforce.com/)**  

  Declarative automation tool within Salesforce for building multi-step workflows, approvals, and record-triggered automations without code.



- **[Zapier](https://zapier.com/)**  

  Leading no-code automation platform connecting 7,000+ apps with multi-step Zaps and AI-powered workflow builder .



- **[Make](https://www.make.com/)**  

  Visual automation platform with scenario builder, routers, loops, error handling, and 2,000+ app connectors .



- **[Microsoft Power Automate](https://powerautomate.microsoft.com/)**  

  Microsoft's automation service with 1,000+ connectors, desktop RPA flows, and AI Builder integration .



- **[Tray.io](https://tray.io/)**  

  Enterprise automation platform with visual workflow builder, universal connectors, and low-code orchestration .



- **[n8n Cloud](https://n8n.io/)**  

  Managed version of the open-source workflow automation tool with 400+ integrations and fair-code licensing .



- **[Workato](https://www.workato.com/)**  

  Enterprise automation platform with low-code recipes, API management, and governance controls .



- **[Kissflow](https://kissflow.com/)**  

  No-code workflow and process automation platform with approvals, forms, and cross-departmental orchestration.



- **[Appian](https://appian.com/)**  

  Enterprise low-code automation platform with process modeling, case management, and RPA orchestration .



- **[Quickbase](https://www.quickbase.com/)**  

  No-code platform for building custom business applications with relational databases and workflow automation .



## Open-Source GitHub Projects



- **[n8n](https://github.com/n8n-io/n8n)**  

  Fair-code workflow automation platform with 400+ integrations, visual builder, custom code nodes (JavaScript/Python), and AI Agent nodes. The leading open-source alternative to Zapier and Make. Self-hosted with no per-task pricing .



- **[Activepieces](https://github.com/activepieces/activepieces)**  

  Open-source no-code AI-first business automation tool with 600+ pieces, visual flow builder, human-in-the-loop approvals, AI agents, and MCP server. MIT licensed, unlimited task execution, 60% of integrations built by users. Alternative to Zapier, Make, and Workato .



- **[Automatisch](https://github.com/automatisch/automatisch)**  

  Open-source business automation tool and Zapier alternative with self-hosting, workflows, and connector framework. AGPL-3.0 licensed .



- **[Huginn](https://github.com/huginn/huginn)**  

  Open-source system for building agents that monitor and act on your behalf — web scraping, notifications, and event automation. MIT licensed .



- **[Windmill](https://github.com/windmill-labs/windmill)**  

  Open-source developer platform to turn scripts into webhooks, workflows, and UIs. Fastest workflow engine (13x vs Airflow). Open-source alternative to Retool and Temporal. GPL-1.0+ licensed, 12,900+ GitHub stars .



- **[Joget](https://github.com/jogetworkflow/jw-community)**  

  Open-source AI Agentic Application Development Platform combining low-code/no-code with AI agents. Visual-first approach for building, automating, and scaling enterprise applications. Trusted by enterprises, governments, and startups .



- **[Corteza](https://github.com/cortezaproject/corteza)**  

  Open-source low-code platform (Apache 2.0) with visual app builder, BPMN-style workflow engine, JavaScript automation scripts, and enterprise CRM. Salesforce skills transfer directly — objects, workflows, and build logic deliberately mirror Salesforce. 2,100+ GitHub stars .



- **[Budibase](https://github.com/Budibase/budibase)**  

  Open-source low-code platform for building business apps and workflows with AI agents. Supports PostgreSQL, MySQL, MSSQL, MongoDB, REST API, Docker, K8s. Self-hosted with full control .



- **[Appsmith](https://github.com/appsmithorg/appsmith)**  

  Open-source low-code platform for building internal tools with 45+ widgets, DB & API connectivity (MySQL, PostgreSQL, MongoDB, GraphQL, REST), and GitHub integration. Trusted for teams needing control .



- **[ToolJet](https://github.com/ToolJet/ToolJet)**  

  Open-source low-code platform with visual app builder and 50+ data source connectors for internal tooling .



- **[ByteChef](https://github.com/bytechef/bytechef)**  

  Open-source low-code API integration and workflow automation platform. Supports Java, JavaScript, Python, and Ruby code blocks with Git-friendly version control. Self-hosted with full data control .



- **[Apache Airflow](https://github.com/apache/airflow)**  

  Workflow orchestration platform with DAG-based scheduling, Python-defined workflows, and rich operator ecosystem for data pipelines .



- **[Temporal](https://github.com/temporalio/temporal)**  

  Durable execution platform for orchestrating long-running workflows with human-in-the-loop steps and multi-service coordination. MIT licensed .



- **[Prefect](https://github.com/PrefectHQ/prefect)**  

  Modern workflow orchestration framework with Python-native flows, dynamic scheduling, and observability .



- **[Trigger.dev](https://github.com/triggerdotdev/trigger.dev)**  

  Open-source background jobs and workflow platform with TypeScript-first approach, durable execution, and no timeout limitations. Apache 2.0 licensed .



- **[Node-RED](https://github.com/node-red/node-red)**  

  Flow-based programming tool for wiring together devices, APIs, and services. Massive node ecosystem for IoT and event-driven automation. Apache 2.0 licensed.



- **[Robot Framework](https://github.com/robotframework/robotframework)**  

  Open-source RPA and test automation framework with keyword-driven approach .



- **[TagUI](https://github.com/aisingapore/TagUI)**  

  Open-source RPA tool for automating web, desktop, and data workflows .



### Additional Strong Open-Source Options



- **[Robocorp](https://github.com/robocorp)** — Python-native RPA platform with open-source tools for automation development .

- **[Apache NiFi](https://github.com/apache/nifi)** — Data flow automation with visual programming and 300+ processors.

- **[Apache Camel](https://github.com/apache/camel)** — Integration framework implementing Enterprise Integration Patterns with 300+ components.

- **[Kestra](https://github.com/kestra-io/kestra)** — Declarative orchestration with YAML workflows and 500+ plugins.

- **[Inngest](https://github.com/inngest/inngest)** — Event-driven workflow engine with durable functions.

- **Queue Infrastructure** — RabbitMQ, Apache Kafka, Redis Streams for reliable task distribution.



**Frameworks for building custom systems**: Combine **n8n** or **Activepieces** for visual workflows, **Windmill** for developer-first scripting, **Corteza** for Salesforce-like app building, **Budibase** or **Appsmith** for internal tools, and **PostgreSQL + Redis** for persistence and queuing to build a complete self-hosted low-code automation stack.
